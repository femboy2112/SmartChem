# SmartChem scientific, mathematical, and architecture audit

**Audit date:** 2026-07-20  
**Scope:** the shared SmartChem working tree, including the audit fixes already present on
this date  
**Goal:** assess what the repository proves, what it calculates, where its numerical and
physical claims are valid, and what architecture can credibly grow into a category-informed
multiphysics simulator

This is a scientific and software audit, not a safety certification. In particular, no
result from the present repository should be used to design, energize, or approach a
high-voltage or radio-frequency apparatus without competent engineering review,
instrumentation, shielding, interlocks, and compliance with applicable standards.

## 1. Executive verdict

SmartChem has a useful core idea, but the defensible version of that idea is narrower and
more powerful than “category theory simplifies all physics.” The repository can become a
**typed physical compiler**: it can use categorical structure to compose systems, enforce
interface and conservation constraints, select a valid representation, and preserve the
provenance and error of every approximation. Category theory does not remove the need to
solve the domain equations, and formal linear combinations are not generally reducible to
independent components in an interacting system.

The current tree is best described as:

> a path category of conserving sequential histories, an additive isolated-species energy
> adapter, several pluggable molecular-energy oracles, and early electrochemical/circuit
> bookkeeping with explicit refusal at unsupported scientific boundaries.

That is a credible foundation. It is not yet a general chemistry simulator, circuit
simulator, Maxwell solver, dynamics engine, or multiscale simulator.

Several high-severity defects found during the audit have already been corrected in the
shared tree:

- the Bohr-to-angstrom gradient chain rule in geometry relaxation;
- optional PySCF import and availability behavior;
- strict CBS request grammar and cardinal ordering;
- enforcement of `max_atoms` and inclusion of calculation settings in persistent-cache
  identity;
- empirical nominal-accuracy lookup by the actual tight-d policy, with unmeasured protocols
  declining rather than inheriting a fabricated finite error bar;
- electron transfer counted by charge quanta with exact typed carrier-inventory matching,
  rather than carrier-object count alone;
- separation of diagnostic `-dE/n` from physical open-circuit voltage;
- validation of thermodynamic-condition coordinates;
- validation of `Estimate`, `Step`, and `Tally` numbers and separation of named systematic
  sources at the `Estimate` layer;
- stronger persistent-cache fingerprints, cross-checks, write merging, and locking;
- immutable model/reference input tables and defensive immutable composition snapshots, so
  a running oracle cannot drift behind a cache identity through in-process table mutation;
- truthful categorical naming: `scheduled_product` is a deterministic serialization, not a
  parallel tensor satisfying interchange.

The principal remaining scientific risks are not small code bugs. They are missing state
identity, missing thermodynamics and kinetics, incomplete electronic-structure validity
diagnostics, absent interaction/environment models, incomplete correlation-aware
uncertainty, and the lack of a typed regime-selection layer.

## 2. What the mathematics currently is

### 2.1 Exact present semantics

Let `Config` be the canonical finite multiset of connected `Molecule` values. The object
operation is commutative multiset union:

```text
A + B = B + A
(A + B) + C = A + (B + C)
A + 0 = A
```

A `Reaction(A, B)` is a finite, validated history

```text
A = X0 -> X1 -> ... -> Xn = B
```

such that every transition conserves atom inventory and total charge. The identity is the
explicit empty history. Sequential composition concatenates histories. An elementary
endomorphism remains a one-step process rather than being collapsed into the identity.
Each elementary transition can carry a stable `generator_id`; the resulting typed
`generator_word` is semantic identity for a route, while the human-readable `name` is not.

This is a **path category of conserving sequential histories**. That description is exact
for the present code.

The mechanism layer is a branching writer computation: each branch carries a state and a
`Tally`, and `bind` concatenates the transition/generator history and accumulates supplied
energy/provenance. This is useful composition machinery, but it does not make the supplied
steps elementary chemistry or their energy sums kinetic rate laws.

### 2.2 Why `scheduled_product` is not a tensor of processes

For `f : A -> B` and `g : C -> D`, the current scheduled operation constructs the linear
history

```text
A + C  --f with C held fixed-->  B + C  --g with B held fixed-->  B + D.
```

It preserves both histories and has a deterministic left-first convention. It is not
parallel composition. In particular, the interchange law would compare two different
orders:

```text
(f scheduled g); (f' scheduled g')  gives  f, g, f', g'
(f; f') scheduled (g; g')           gives  f, f', g, g'.
```

Those histories are not equal in the present path representation. Object commutativity
does not repair morphism-level interchange, and an object-level braid is an identity only
because `Config` has already forgotten ordering. Accordingly, `Reaction.tensor` is now a
compatibility alias for `scheduled_product`, not evidence of a symmetric monoidal category.

### 2.3 Present energy semantics

The current thermochemistry adapter defines the isolated-species potential

```text
E(A) = sum_i E(species_i)
dE(f : A -> B) = E(B) - E(A).
```

Consequences that are exact **inside this model** are:

```text
dE(identity_A) = 0
dE(g after f) = dE(f) + dE(g)
unchanged isolated species cancel from an endpoint difference.
```

Categorically, the clean target is the translation category of real energy levels:
`F(A)=E(A)` and `F(f)` is the arrow from `E(A)` to `E(B)` labeled by `E(B)-E(A)`.
Equivalently, `dE` is an additive cocycle on the path category. This is a functor for
sequential composition. It is not presently a strong monoidal functor of processes because
the source has no genuine morphism tensor and the physical object energy is additive only
under the isolated-species approximation.

These are properties of a potential difference and the assumed separability of the object
energy. They do not show that two molecules in one vessel have no interaction energy. A
solvent molecule, catalyst, cage, electrode, antenna element, or nearby resonator can be
spelled identically at both endpoints while changing the field, binding, polarization, or
free energy of everything around it.

### 2.4 Deferred open-process and string-diagram semantics

A real cross-domain physical IR should represent **ports, connections, and hidden internal
state**, not only endpoint multisets and a linear log. The recommended mathematical target
is an open-process graph, with decorated cospans/corelations or an equivalent typed
hypergraph/string-diagram representation:

- an object is a typed boundary: electrical terminals, chemical material ports, thermal
  surfaces, mechanical frames, optical/radiation modes, fluid inlets, or field boundaries;
- a box carries equations, state, parameters, validity conditions, conserved quantities,
  and uncertainty sources;
- composition glues compatible ports and eliminates internal boundary variables;
- tensor is disjoint juxtaposition;
- parallel circuit connection is **not** tensor: it is port identification/gluing, often
  represented through Frobenius structure;
- feedback closes compatible ports while preserving algebraic-loop/DAE diagnostics;
- black-boxing maps an internal implementation to a boundary behavior such as an impedance,
  scattering relation, constitutive relation, transfer operator, or port-Hamiltonian model.

String diagrams should be a syntax and verification layer for composition. They do not
determine the component physics. Interchange can be imposed only when independent boxes
really commute or when the process-graph quotient makes scheduling unobservable.

### 3.2 P0 boundaries still unresolved

These items can still produce a plausible answer for the wrong physical species or attach a
confidence statement the calculation did not earn.

#### Species and electronic-state identity

`Molecule` identity does not yet encode all physically decisive state:

- spin multiplicity and a stable electronic-state label;
- atom-resolved formal charge/resonance choice where it affects initialization;
- isotope/isotopologue;
- stereochemistry and conformer geometry;
- phase and standard state.

The polyatomic PySCF path chooses the lowest spin compatible with electron-count parity.
Even-electron triplet methylene and many transition-metal systems are immediate
counterexamples. Diatomic geometry and spin are keyed by formula, so incompatible bond
orders/electronic states can alias the same table entry. Until state identity is explicit,
the oracle should decline any request whose requested graph/state is not demonstrably the
tabulated reference state.

**Required fix:** introduce `SpeciesState` containing total charge, multiplicity (`2S+1` or
PySCF `2S` with unambiguous naming), electronic-state ID, isotope vector, conformer/geometry
ID, phase, and reference convention. Put it in equality, cache keys, calculation specs, and
result provenance. Enumerate plausible spin states where necessary; run SCF stability and
spin-contamination checks; decline or escalate on multireference diagnostics.

**Acceptance tests:** triplet and singlet CH2 must be different species and cache keys; two
isotopologues must have different masses/ZPE; two conformers must not collide; single- and
triple-bond diatomic labels must never silently receive identical reference-state results.

#### Electronic-structure protocol identity

The present coupled-cluster path checks convergence but not wavefunction stability,
alternative SCF solutions, spin contamination, or single-reference validity. PySCF CCSD
correlates all electrons unless frozen orbitals are specified, while cc-pVXZ families are
usually used as valence-correlation sets. That ambiguity is material for second-row and
heavier systems.

**Required fix:** make frozen-core/all-electron policy explicit. Use a validated composite
protocol: for example, frozen-core cc-pVXZ valence correlation plus a separately calibrated
core-valence correction with cc-pCVXZ, or an explicit all-electron core-valence basis. Add
SCF stability, multiple guesses, `<S^2>`, and appropriate coupled-cluster diagnostics. Add
scalar-relativistic, spin-orbit, and ECP choices for heavy elements. Refuse when diagnostics
are outside the calibrated regime.

#### Uncertainty semantics

Named systematic sources are a meaningful improvement, but the remaining scalar
`uncertainty_ev` is still combined in quadrature as though repeated model errors were
independent standard deviations. A benchmark MAE is neither a per-species standard
deviation nor a confidence interval. Reusing the same modeled quantity twice is correlated:
`2A` should double its shared epistemic coefficient, while `A-A` should cancel it.

The code now gets exact repeated-use scaling and algebraic correction propagation right and
prevents cross-kind correction cancellation. It still assumes perfect within-source
correlation without evidence. Equal CBS correction displacements may cancel algebraically,
but that does not establish that unknown residual basis errors cancel. Likewise, the
selected-diatomic 9.1% HF-harmonic ZPE displacement lacks coefficient uncertainty and
species-residual scatter.

**Required fix:** implement the source-aware uncertainty graph in Section 6.3. Keep numerical
convergence, discretization, parameter/reference, stochastic sampling, and model discrepancy
separate. Report coverage (`1 sigma`, `95%`, bound, or validation MAE) explicitly.

**Acceptance tests:** exact reuse/cancellation, shared-source scaling, independent-source
quadrature, correlated covariance, Monte Carlo comparison for a nonlinear transform, and
coverage on a held-out validation set.

## 4. P1 findings: model coverage, numerical robustness, and scientific completeness

The present PySCF module contains a nonrelativistic Born-Oppenheimer electronic-structure
path with HF, MP2, CCSD, and CCSD(T) implementations and correlation-consistent basis/CBS
policies. Public estimates are narrower: the oracle explicitly declines charged molecules,
unknown elements/states, unmeasured calculation protocols—including currently MP2, CCSD,
optimized-geometry, and polyatomic profiles—and species above the configured atom cap.
Tabulated fixed-geometry diatomics use supplied
equilibrium bond lengths, harmonic frequencies, and spin labels. Requesting diatomic
geometry optimization currently replaces the bond length but not the table frequency/spin.
The internal polyatomic research path uses a graph-derived seed and currently assumes the
lowest spin compatible with electron-count parity, but the public oracle declines it before
backend work because no polyatomic validation profile exists. `Conditions` is not passed
into the Hamiltonian. These are calculation boundaries, not incidental missing features.

### 4.1 Geometry, Hessians, and zero-point energy

The Eckart-style projection and mass weighting are a strong part of the current code. The
same Hessian has been compared with PySCF's independently implemented harmonic analysis.
That verifies the local vibrational algebra, not the correctness of the electronic surface,
the electronic state, or the global molecular structure.

Remaining boundaries:

- a positive Hessian certifies a **local** minimum on the chosen approximate surface, not
  the global ground structure;
- graph/VSEPR seeding is not a conformer or stereoisomer search and is fragile for rings;
- any tiny negative numerical mode is currently treated as a saddle without a calibrated
  frequency threshold/tighter rerun policy;
- finite-temperature entropy needs RRHO or quasi-RRHO treatment and hindered rotors;
- a 9.1% aggregate HF-harmonic displacement measured on 23 diatomics is not a universal
  polyatomic uncertainty and does not separate electronic-method from anharmonic error;
- `1/2 omega_e` omits anharmonic spectroscopic terms such as `-1/4 omega_e x_e`;
- computed natural-average masses and spectroscopic isotopologue data need an explicit
  isotope convention;
- an optimized diatomic must receive frequencies from the optimized geometry/tier, not a
  table frequency or silent zero for an unlisted formula.

Recommended geometry ladder:

1. deterministic distance-geometry seeds with explicit stereo/ring closure;
2. broad conformer generation with a cheap model (for example xTB or a force field);
3. DFT or another calibrated geometry/frequency tier;
4. high-level single points on retained minima;
5. conformer/spin ensemble free energy, not “lowest seed wins.”

### 4.2 CBS is an asymptotic model, not an identity

The implemented two-point correlation extrapolation

```text
E_corr(infinity) = (X^3 E_corr(X) - Y^3 E_corr(Y)) / (X^3 - Y^3)
```

is algebraically correct. Its premise is empirical/asymptotic. It can fail when TZ/QZ is
not in the smooth `X^-3` tail, for diffuse ionic states, open shells, inconsistent core
correlation, or nonmonotone sequences. The repository's own NaCl result demonstrates this:
plain QZ was closer to reference than the extrapolated result.

Add monotonicity and correction-size diagnostics, optional three-point checks, and a
regime-specific calibration. A large/nonmonotone correction should trigger a declared
sensitivity warning, a regime-calibrated uncertainty treatment, a larger explicit basis,
or refusal; it should never inherit the average performance of a different regime.

### 4.3 Thermodynamics and ensembles

For species `i` at a defined state, a practical molecular free-energy model has the form
below when every energy is converted to a consistent **molar** convention:

```text
G_i(T,p,a_i) = E_elec + ZPE + [H_i(T)-H_i(0)] - T S_i(T)
               + G_solv + G_phase/interface + R T ln(a_i/a_standard).
Delta_r G = sum_i nu_i mu_i
K = exp(-Delta_r G_standard / (R T)).
```

Conformer/spin ensembles require

```text
G_ensemble = -R T ln(sum_i g_i exp(-G_i/(R T))).
```

`Conditions` presently provides validated coordinates, not these physics. Static dielectric
alone does not identify a solvent model; SMD, for example, uses additional solvent
descriptors and non-electrostatic terms. Ions also require charge-aware electronic
calculations and standard-state consistency. Implementing a fake dielectric shift would be
worse than refusing.

The compatibility predicate `is_exothermic` retains its historical name but decides only the
sign of generic endpoint `dE`. `favourability` now emits “energy lowering/raising” and labels
the scalar uncertainty as a coverage-unspecified scale rather than a confidence bound.

Cell factorization correctly preserves the electron count that disappears from the net
endpoint spelling. It must not be interpreted as permission to select an arbitrary `n` to
obtain a desired voltage: half-reactions, electrode species, reaction extent, and charge
transfer must be physically admissible, and rescaling a reaction rescales `Delta G` and `n`
together.

### 4.4 Kinetics, transition states, and pathways

Endpoint energy is a state function. Therefore all physically consistent routes between
the same endpoints telescope to the same total `dE`; sorting mechanisms by endpoint energy
cannot identify the fastest mechanism. The former cumulative-downhill prefix filter also
deleted valid routes with obligatory uphill intermediates; the corrected implementation
applies its compatibility `spontaneous_only` predicate only to completed routes.

A physical kinetics layer needs:

- transition-state structures with one physically significant imaginary mode, after a
  calibrated numerical-noise/refinement policy (the current code flags every negative mode);
- intrinsic reaction-coordinate or equivalent endpoint connectivity checks;
- free-energy barriers `Delta G^‡`;
- rate models such as `k = kappa (k_B T/h) exp(-Delta G^‡/(R T))` where transition-state
  theory is valid;
- tunneling, solvent dynamics, nonadiabatic, or diffusion corrections when their regime
  tests demand them;
- deterministic stiff mass-action integration and stochastic Gillespie simulation;
- detailed-balance checks using dimensionless activities and explicit standard-state factors.
  Only under a compatible nondimensionalized convention may a forward/reverse kinetic ratio
  be identified directly with `K = exp(-Delta G_standard/(R T))`; raw mass-action rate
  constants can have different units when molecularities differ.

The current pathway search is discrete supplied-step enumeration and no longer globally
sorts alternatives by incomparable endpoint-energy numbers. Its `best_route` helper refuses
mixed methods and alternative estimates rather than implying comparability. Rank routes by
barriers, rate/flux, selectivity, yield, resource cost, or a user-supplied objective only
after those quantities exist.

### 4.5 Environment and interaction energy

The isolated-species sum is a legitimate reference model. It must not be mistaken for an
interacting vessel. Future context should include, as applicable:

- solvent identity/model, temperature-dependent solvent properties, ionic strength, pH,
  concentrations and activities;
- phase, density, pressure, interfaces, electrode potential, and boundary reservoirs;
- external field vector, frequency spectrum, intensity, polarization, and boundary
  conditions;
- geometry, separation, orientation, mutual coupling, and finite-size conditions.

Every solver must declare exactly which coordinates it consumes. A response surface that
is flat because the backend ignores all axes is not an environmental prediction. The
frozen heuristic now refuses nonstandard `Env` values rather than exporting its vacuum
conditional MAE to water, temperature, pressure, or illumination changes.

## 5. Performance audit

### 5.1 Useful optimizations already present

- conservation and structural invalidity are rejected before expensive oracle calls;
- atomic electronic energies are reused inside the PySCF oracle;
- per-run and persistent caches avoid repeated species calculations;
- persistent cache keys now carry much more calculation identity and code provenance;
- the previous converged density is reused as an SCF guess along a geometry path, with a
  fallback to a fresh guess;
- geometry and high-level energy tiers can be separated explicitly;
- `relax` reuses the optimizer's final Jacobian rather than purchasing another SCF gradient;
- canonicalization uses structural refinement when the simple permutation space exceeds a
  bound and declines rather than returning a noncanonical key.

### 5.2 Dominant costs and scaling boundaries

Conventional electronic-structure costs rise steeply with basis size: representative formal
scalings are approximately HF `N^4`, MP2 `N^5`, CCSD `N^6`, and perturbative triples `N^7`.
Constants, sparsity, symmetry, and implementation matter, but category-level algebra cannot
remove the wavefunction cost of a calculation that still has to be performed.

Other likely bottlenecks are:

- Cartesian relaxation of flexible molecules;
- conformer/spin enumeration;
- graph canonicalization on highly symmetric, repeated-element graphs;
- JSON cache loading/rewriting when the database becomes large;
- serial CBS and species workloads that could run independently;
- full-wave meshes and coupled multiphysics iterations in the future.

### 5.3 Safe performance roadmap

1. Profile first, using separate cold-compute, warm-cache, and orchestration timings.
2. Use a staged chemistry ladder: xTB/DFT conformers and geometries, calibrated frequency
   tier, then sparse high-level single points/composite corrections.
3. Adopt internal-coordinate optimization (for example through geomeTRIC/PyBerny) when the
   current Cartesian method crosses a measured size/flexibility threshold.
4. Make frozen-core, density fitting, symmetry, integral reuse, and task parallelism explicit
   calculation-spec choices, each with validation against the parent method.
5. Consider GPU4PySCF only for supported methods and verify CPU/GPU agreement within a
   declared numerical tolerance.
6. Replace the monolithic JSON cache with a content-addressed database or SQLite/WAL when
   profiling shows file rewrite/contention dominates. Preserve immutable calculation specs,
   schema versions, checksums, and refusal classification.
7. For circuits/fields, use sparse matrices, symbolic factorization reuse, adaptive meshes,
   model-order reduction, and parallel frequency/parameter sweeps only after passivity and
   error estimators are in place.

An optimization is “free” only when it preserves the same mathematical problem and the
same result within a stated numerical tolerance. Any cheaper physical model is an
approximation and must carry its own validation domain and discrepancy.

## 6. Proposed typed Physical IR and compiler

The central architectural recommendation is to stop treating “simplification” as an
untyped algebraic rewrite and make it a compilation problem.

### 6.1 Core IR records

| Record | Required content |
|---|---|
| `Quantity` | value, physical dimension, unit, frame/orientation where relevant, uncertainty source expression |
| `PhysicalState` | time/frequency domain, thermodynamic state, fields, inventories, geometry/mesh, phase and boundary conditions |
| `Component` | stable ID, domain type, internal variables, parameters/materials, typed ports, constitutive equations |
| `Port` | effort/flow or field variables, orientation/sign convention, conserved quantity, admissible connection type |
| `Connection` | port gluing, constraints, junction law, topology and multiplicity |
| `ModelSpec` | governing equations, assumptions, validity predicate, parameters, numerical/discretization choices, conserved quantities |
| `SolverSpec` | algorithm/version, tolerances, mesh/timestep/basis, convergence/refinement policy, backend/hardware |
| `Adapter` | source/target representations, exchanged observables, coarse-graining rule, validity/error, one- or two-way coupling |
| `ObservableRequest` | typed output, tolerance/coverage target, space/time/frequency support |
| `Certificate` | selected model chain, exact rewrites, approximation errors, residuals, refinement evidence, provenance and refusals |

Species identity should be one domain-specific `Component`/state record, not overloaded into
an opaque string. Circuit terminals, thermal surfaces, chemical reservoirs, mechanical
frames, and electromagnetic boundaries should be different port types that cannot be
silently connected.

### 6.2 Compilation pipeline

1. **Parse and canonicalize.** Resolve stable identities, units, coordinates, graph/mesh,
   species state, ports, and user observables.
2. **Type and conservation check.** Enforce dimensions, inventory, charge/current, energy,
   orientation, boundary compatibility, and legal port gluing.
3. **Extract regime parameters.** Compute dimensionless/scale diagnostics such as electrical
   size, skin depth ratio, Knudsen, Mach, Reynolds, Peclet, Damkohler, Debye-length ratio,
   nonadiabatic measures, `Z alpha`, `v/c`, and gravitational curvature.
4. **Enumerate valid model chains.** A solver is a candidate only if its `valid_if` predicate
   and required inputs are satisfied.
5. **Rewrite exactly.** Apply conservation pruning, graph isomorphism, symmetry, linear
   superposition, block diagonalization, and boundary elimination only where proven exact.
6. **Choose approximations.** Minimize estimated cost subject to an output error/coverage
   budget; never choose solely by fastest runtime.
7. **Assemble and solve.** Build sparse algebraic/ODE/DAE/PDE systems and explicit coupling
   iterations.
8. **Verify.** Check solver convergence, conservation/passivity, residuals, mesh/timestep/
   basis refinement, and agreement in overlap regions between adjacent models.
9. **Emit a certificate.** Record why each model was valid, every source/parameter version,
   what was refused, and how uncertainty propagated.

No rewrite may cross a model boundary without one of:

- a proof of equivalence;
- a calibrated approximation with a validity predicate and discrepancy;
- a user-authorized assumption that is surfaced in the certificate.

The user's formal-linear-combination idea fits here as one IR layer, not the whole
semantics. Stoichiometric combinations can live in a free abelian group/module; component
assemblies can live in a typed free symmetric-monoidal/open-graph syntax; linearized solver
states can use vector spaces. The compiler may then choose guarded rewrites such as:

| Rewrite | Valid only when |
|---|---|
| independent sum to block-diagonal solve | coupling terms are identically zero or bounded below the requested tolerance |
| superposition/transfer-function reduction | governing equations and boundary conditions are linear in the relevant range |
| field model to lumped MNA | propagation/field variation is negligible and extracted elements remain passive/causal |
| distributed structure to a reduced multiport | port behavior converges over the requested band and reduction preserves stability/passivity |
| fast subsystem to quasi-steady state | timescale separation is measured and initial/boundary layers are irrelevant to the observable |
| molecular ensemble to one conformer | omitted Boltzmann weight is below a declared free-energy/error threshold |
| explicit particles to continuum | closure is valid, sampling volume is representative, and Knudsen/fluctuation gates pass |
| symmetry quotient | equations, materials, loads, boundary conditions, and requested observable share the symmetry |

This turns “easiest mathematical form” into a checkable optimization objective: cheapest
valid representation meeting an observable-specific tolerance, rather than the smallest
symbolic expression.

### 6.3 Source-aware uncertainty

Represent a locally linear uncertain result as an affine/source expression

```text
Y = y0 + sum_s c_s xi_s,
```

where each `xi_s` has a stable source ID and a declared distribution, bound, or covariance
relationship. For vector/nonlinear models use Jacobians or ensemble propagation:

```text
Sigma_Y = J Sigma_X J^T + Sigma_model + Sigma_numerical.
```

Keep at least these source classes separate:

- measured parameter/reference uncertainty;
- stochastic/sampling uncertainty;
- numerical convergence and discretization error;
- basis/model-truncation discrepancy;
- calibration/fit uncertainty;
- scenario uncertainty and unresolved variability.

An MAE belongs to validation metadata over a named population. It becomes a predictive
distribution only after calibration and coverage testing. Identical reused sources are
fully correlated by default; independent sources require an explicit independence claim.
This is consistent with the covariance treatment in the JCGM Guide to the Expression of
Uncertainty in Measurement.

## 7. Multiscale ladder: quantum through relativistic regimes

The ladder is selected by regime, not merely by geometric size. Relativistic corrections
can matter inside an atom; continuum models can matter at micrometers; Maxwell's equations
are already special-relativistic field equations. The current element-symbol conservation
law is specifically a chemistry law: it intentionally makes transmutation impossible. A
nuclear/particle domain must instead use typed nuclides and particles and enforce the
applicable charge, baryon/lepton-number, four-momentum, angular-momentum, and energy/rest-
mass bookkeeping without weakening chemistry's stronger invariant.

| Layer | Representative models | Validity questions/gates | Upward handoff |
|---|---|---|---|
| Subatomic/nuclear/particle | QED/Standard-Model calculations, effective field theories, evaluated nuclear data, particle transport/Monte Carlo | typed nuclide/state; energy versus EFT/data coverage; applicable conserved quantum numbers and four-momentum; interaction cross sections; radiation mean free path | cross sections, decay spectra, Q values, stopping power, transmutation/source terms |
| Relativistic electronic structure | scalar-relativistic Hamiltonians, spin-orbit methods, four-component methods where needed | `Z alpha`, target accuracy, spin-orbit scale, field strength | energies, states, polarizabilities, effective core parameters |
| Nonrelativistic electronic structure | HF/DFT/post-HF, periodic electronic structure | Born-Oppenheimer separation; state/multiplicity; single-reference diagnostics; basis/core/relativity error | potential-energy surfaces, forces, charges, rates, spectra, response tensors |
| Nonadiabatic/quantum nuclei | TDDFT/wavefunction dynamics, surface hopping, path integrals | electronic gaps/couplings versus nuclear timescale; coherence/decoherence; isotope effects | transition probabilities, photochemical rates, corrected free energies |
| Atomistic molecular | classical/reactive MD, ab initio MD | force-field domain; timestep stability; sampling/convergence; finite size | free energies, transport coefficients, constitutive data, reaction coordinates |
| Coarse-grained/mesoscale | coarse-grained MD, kinetic Monte Carlo, population balances | scale separation and closure; retained variables; memory/non-Markov effects | effective rates, diffusivities, rheology, source terms |
| Chemical network and transport | mass-action/stochastic kinetics, reaction-diffusion, electrochemistry | Damkohler number, well-mixed assumption, detailed balance, electroneutrality/Poisson coupling | heat/species/current source terms, conductivity/permittivity changes |
| Continuum matter | heat, solid mechanics, CFD, plasma fluid models | Knudsen, Mach, Reynolds, Peclet, Debye-length ratios; constitutive range | geometry/deformation, temperature/flow/pressure/material fields |
| Discrete classical mechanics | rigid/multibody dynamics, contact, orbital and N-body mechanics | rigidity/contact model, constraint rank, timestep/symplectic error, force range, continuum versus discrete validity | poses, loads, momentum/energy exchange, moving EM/material boundaries |
| Lumped electrical | MNA/state-space/DAE circuits | electrical size and propagation delay; element locality; linear/nonlinear ranges | port voltages/currents, dissipated power, drive/load conditions |
| Distributed electromagnetic | transmission line, multiconductor RLGC, PEEC | dominant modes, cross-section uniformity, skin/proximity scales, wavelength | S/ABCD parameters, currents/charges, reduced multiports |
| Full-wave electromagnetic | FDTD, FEM, MoM/BEM, eigenmode solvers | mesh/CFL/PML/refinement; dispersive material validity; open-boundary treatment | fields, Poynting flux, forces, losses, radiation/mutual coupling |
| Geometric/radiative transport | geometric optics, radiative transfer, coherent/incoherent hybrid models | wavelength versus feature/correlation length; phase coherence; scattering/absorption regime; optical depth | irradiance, momentum/heat deposition, photochemical source terms |
| Special-relativistic mechanics/transport | covariant particle/fluid dynamics | `beta=v/c`, required timing/phase precision | relativistic stress-energy/current sources |
| General relativity | post-Newtonian or numerical GR | gravitational potential/curvature and demanded precision | metric/geodesic/redshift corrections |

Cross-scale adapters should exchange only sufficient observables and carry their provenance:
QC to MD supplies forces/parameters/free energies; MD to continuum supplies transport and
constitutive laws; EM supplies `J dot E`, forces, and photochemical source terms; chemistry
and plasma models update species, conductivity, and permittivity; temperature/deformation
feeds all material and rate laws. One-way coupling is allowed only with demonstrated weak
feedback. Otherwise use conservative two-way iteration/operator splitting with explicit
residuals and no double counting of energy terms. Quantum response or measurements may feed
EM only through a homogenized, frequency/state-dependent susceptibility, permittivity,
permeability, or conductivity with explicit scale separation, causality, and passivity
checks. Relativistic adapters must declare reference frame, time coordinate, simultaneity/
phase convention, and stress-energy/current transformation, then recover the lower theory
in the appropriate limit.

## 8. Tesla coils, resonant circuits, antennas, and high voltage

This is the recommended first end-to-end multiphysics vertical because it exercises the
project's central ideas—composition, representation selection, conservation, uncertainty,
and scale escalation—without pretending that molecular CCSD(T) is the right solver for a
coil.

### 8.1 Stage A: units, ports, and sparse MNA

Implement electrical nodes/ports and sparse modified nodal analysis for DC, AC phasor, and
transient DAE problems:

- resistors, capacitors, inductors, independent/dependent sources;
- nonlinear device residual/Jacobian interface;
- mutual inductance and transformer sign/dot conventions;
- multiports and measured/tabulated impedance or S-parameter components;
- initial conditions, events, and stiff integration;
- KCL/KVL, passivity, energy, and dimensional checks.

**Gate:** use lumped elements only when propagation delay and field variation across each
component are negligible for the requested tolerance. Electrical size `kL = 2 pi L/lambda`
and rise-time versus flight-time are diagnostics, not universal hard thresholds.

**Acceptance:** analytic RC/RL transients, series/parallel RLC resonance and Bode plots,
energy decay in a passive network, ideal-transformer/mutual-inductance sign tests, sparse
versus dense agreement, and convergence under timestep/tolerance refinement.

### 8.2 Stage B: coupled lossy resonators (Tesla reduced model)

Represent primary and secondary as two lossy resonators with

```text
M = k sqrt(L1 L2),          |k| <= 1,
Q = omega W_stored / P_loss.
```

Include drive impedance, loaded/unloaded Q, top-load and parasitic capacitance, winding and
dielectric loss, mutual coupling, ring-up/ring-down, eigenfrequency splitting, and load/
radiation resistance. Solve the coupled eigenproblem and transient, then compare it with
MNA.

**Acceptance:** uncoupled limit as `k -> 0`, mode splitting against the analytic two-mode
solution, energy decay matching Q, no growth without source/initial energy, reciprocity for
passive reciprocal coupling, and measured low-voltage coil impedance/ringdown within a
declared uncertainty.

Resonance can magnify voltage or circulating reactive energy. It does not create net
energy. Increased voltage trades against current, bandwidth, loading, detuning, and loss.

### 8.3 Stage C: distributed coils and transmission lines

Escalate to frequency-dependent multiconductor RLGC, a helical transmission-line model, or
PEEC when the coil is not electrically small, self-resonance/higher modes matter, or skin/
proximity effects invalidate constant lumped elements. For one uniform scalar line or one
decoupled mode,

```text
gamma = sqrt((R' + j omega L')(G' + j omega C'))
Z0    = sqrt((R' + j omega L')/(G' + j omega C')).
```

For a multiconductor line, `R'`, `L'`, `G'`, and `C'` are matrices and the telegrapher
equations are `dV/dz = -(R'+j omega L') I` and `dI/dz = -(G'+j omega C') V`; propagation
constants and modal impedances come from a matrix eigenproblem, not elementwise scalar roots.

Compute propagation, reflection, standing waves, ABCD/S parameters, terminal impedance,
and reduced multiports. Material and geometry extraction must be frequency and temperature
aware.

**Acceptance:** telegrapher-equation analytic cases, passivity/causality of extracted
multiports, convergence with segment count, agreement with MNA in the electrically small
overlap regime, and comparison with measured impedance/S11 across the first resonances.

### 8.4 Stage D: full Maxwell fields and antennas

Provide complementary solvers rather than one universal mesh:

- FEM frequency/eigenmode analysis for bounded complex geometry and material domains;
- thin-wire MoM/EFIE or BEM for open conductors/antennas;
- FDTD for broadband transients with explicit CFL stability, dispersive updates, and PML;
- optional model-order reduction to a passive multiport for reuse by the circuit solver.

Solve the global coupled field before integrating local loss or received power. Nearby
absorbers, coils, antennas, structures, and the ground mutually load, scatter, shield, and
detune one another; their powers cannot generally be computed independently and summed
before the field solve.

Outputs include near/far fields, Poynting flux, stored energy, radiation resistance,
efficiency, mutual impedance/coupling, force, S parameters, and exposure metrics.

**Acceptance:** cavity and transmission-line modes, dipole impedance/pattern, plane-wave
reflection/transmission, Poynting energy closure, reciprocity where applicable, mesh and
timestep convergence, PML reflection tests, and MNA/RLGC/full-wave agreement in overlap
regimes.

### 8.5 Stage E: materials, thermal coupling, and high voltage

Material laws must be causal, passive where appropriate, and state dependent:

- complex `epsilon(omega,T,E)`, `mu(omega,T,H)`, and `sigma(omega,T,E)`;
- Debye/Drude/Lorentz dispersion and Kramers-Kronig-consistent parameterizations;
- skin/proximity, dielectric, eddy-current, core, saturation, and hysteresis losses;
- Joule/field loss to heat, then temperature back to resistance/material parameters;
- thermal conduction/convection/radiation and thermo-mechanical deformation where needed.

For high voltage, begin with electrostatic field enhancement and empirical insulation
limits, then distinguish regimes:

- Paschen-type gas breakdown only for its approximate uniform-field/equilibrium gap regime;
- corona and partial discharge at sharp/nonuniform electrodes;
- surface tracking and dielectric aging;
- streamer/leader and space-charge plasma models when discharge reshapes the field;
- plasma chemistry for ozone/NOx and erosion when exposure or lifetime is an observable.

**Acceptance:** electrostatic benchmark geometries, skin-depth and heating analytic cases,
energy-conservative electrothermal coupling, grid/time convergence, temperature-dependent
resonance shift, and carefully controlled low-energy experiments before any high-voltage
validation.

### 8.6 Validity gates and safety invariants

| Decision | Required diagnostics |
|---|---|
| Lumped versus distributed | `kL`, flight time/rise time, self-resonance, current/charge uniformity |
| RLGC/PEEC versus full wave | cross-section/mode assumptions, bends/fringing/radiation, material dispersion, requested near/far-field observable |
| Constant versus frequency-dependent conductor | skin depth/conductor dimensions, proximity spacing, surface roughness, temperature |
| Linear versus nonlinear magnetic/dielectric model | field versus saturation/coercive/breakdown range, harmonic content, hysteresis/loss evidence |
| One-way versus two-way thermal coupling | predicted temperature rise and sensitivity of electrical/material parameters |
| Electrostatic/Paschen versus discharge plasma | field nonuniformity, pressure-gap range, space charge, ionization timescale and density |
| Classical versus quantum/relativistic carrier model | coherence/de Broglie scale, photon/electron energy, `v/c`, material/state requirements |

Hard safety invariants should include:

- stored energy `1/2 v^T C v + 1/2 i^T L i` for coupled linear lumped models (including
  mutual terms), appropriate constitutive/field-energy integrals for nonlinear or dispersive
  media, and maximum credible fault energy;
- integral Poynting/component energy balance;
- passivity for components declared passive;
- touch, arc, RF current, thermal/fire, EMI, and ozone/chemical hazard reporting;
- explicit warning that a numerical field result is not an insulation-clearance or human-
  exposure certification.

Any “over-unity,” “free energy,” or source-free steady power result is a failed model or
measurement until proven otherwise. Historical or speculative Tesla claims should enter as
hypotheses with a Maxwell-consistent quantitative prediction, a falsifier, and independent
measurement—not as alternate conservation laws. Earth/ground propagation can be modeled,
but exotic longitudinal or non-Maxwellian modes must beat a calibrated conventional model
on blinded data before entering the production solver registry.

## 10. Known limitations after the current fixes

- The current category is sequential bookkeeping, not an open-system/string-diagram SMC.
- The structural layer enforces graph shape and inventory, not chemical valence,
  realizability, thermodynamic accessibility, or kinetics.
- `generator_id` is optional; two physically distinct, unidentified generators with the
  same typed endpoints still have the same generator word.
- Direct construction of the low-level `generator_word` field can bypass the normal
  `generator_id` namespace guard; a future generator registry/factory should own this field.
- Object additivity is an isolated-species approximation, not universal interaction physics.
- `is_regenerated` proves stoichiometric regeneration, not catalytic participation or rate
  enhancement; `is_catalytic` remains only a compatibility alias.
- Displayed mechanism energy does not determine kinetics or the best route.
- The PySCF benchmark is small, diatomic, neutral, selected during model/policy work, and
  not an independent broad validation. The historical `test` partition has been inspected.
- Several compact diatomic source labels do not independently prove D0 versus D298
  convention, and the reference uncertainty fields are curation scales rather than one
  executable, covariance-aware coverage model. A primary-record provenance audit and a new
  locked external validation set are required.
- Ions, explicit electronic states, reliable open-shell polyatomics, heavy-element
  relativity, excited states, solids, and periodic matter are not covered robustly.
- Geometry is a local search with no general conformer/stereo/ring solution.
- Harmonic ZPE and its selected-diatomic displacement are not complete finite-temperature
  thermochemistry or a calibrated residual-error model.
- `Conditions` is a validated coordinate type, not a solvent/field/phase model.
- OCV, Nernst response, electrode interfaces, transport polarization, and discharge dynamics
  are absent and correctly not inferred from `dE`; the bundled Zn/MnO2 factorization is a
  simplified structural example rather than a complete commercial-AA mechanism.
- Scalar random uncertainty remains correlation-incomplete despite named systematic terms;
  `Tally` still has no named-systematic or covariance channel.
- Cache identity and record integrity are much stronger but still depend on every future
  physical parameter being added to an immutable calculation spec; hashing is not a
  security boundary and source hashing is not a substitute for that spec.
- There is no MNA, transmission-line, Maxwell, antenna, plasma, CFD, structural, or
  relativistic solver in the repository today. There is also no nuclear/particle transport,
  transmutation, rigid/multibody/contact, orbital/N-body, or radiative-transfer solver.
- No simulation result is a high-voltage, RF-exposure, insulation, EMC, chemical, or human-
  safety certification.

## 13. Final recommendation

Keep the repository's emerging “decline rather than invent” discipline as the primary
design invariant. Build the next system around a typed Physical IR, open ports, immutable
calculation specifications, explicit validity gates, and source-aware uncertainty. Use the
Tesla/coupled-resonator vertical to prove that this architecture can select among lumped,
distributed, full-wave, and thermal/high-voltage representations without violating energy
conservation or hiding model changes. In parallel, harden molecular species identity and
thermodynamics before expanding chemistry claims.

The most valuable role of category theory here is not to promise effortless universal
simplification. It is to make illegal compositions unrepresentable, valid compositions
auditable, representation changes explicit, and approximations unable to shed their domain
or uncertainty as they move through the system.
