## The rule and why R28 deferred it

Rule 1b ranks the **duplicate atoms** in the CIP hierarchical digraph (the phantom atoms created for multiple bonds and
ring closures) by the *hierarchical rank of the node each duplicate represents*. R28 deferred it on a soundness asymmetry:
a duplicate-rank pre-pass is CIP's most error-prone region, and a subtly-wrong computed rank **MISLABELS** (fabrication)
rather than defers — so it must not be built without (a) a real decisive molecule and (b) an **external CIP oracle** to
verify that molecule's true label (hand-deriving both the label and the code that matches it is the "checks derived from
their own subject" trap the project has repeatedly been burned by).

## The investigation (oracle-driven, RDKit `rdCIPLabeler`)

RDKit (an accurate reference CIP labeller) was installed **into the dev venv only** as an external oracle — it is a
legitimate optional *probe* dependency, **absent from the runtime and from the committed test environment** (the committed
harness bakes RDKit's labels as frozen constants and its cross-check skips when rdkit is absent). Three regimes, each
comparing the accurate oracle against the shipped `cip_labels`, all reproduced by committed generators in
`experiments/cip_rule1b_consumer_probe.py`:

1. **Acyclic centres (tree digraphs)** — a committed sweep of **992** acyclic, neutral stereocentres
   `[C@](L1)(L2)(spectator)(spectator)` over a rich ligand set. **0 cases where RDKit assigns a label and our namer
   defers.** For every acyclic stereocentre RDKit resolves, our Rule-1a+2 namer resolves it to the *same* label.
2. **Ring-substituent, off-ring centres (NON-tree digraphs)** — the class a first pass missed (a stereocentre off any ring
   but bearing a ring substituent *stays in scope*; its digraph is not a tree). A committed sweep of **60** such
   stereocentres finds **24 in-scope deferrals where RDKit labels — and ALL 24 are triggered by ring UNSATURATION** (a ring
   double bond). Zero saturated-ring in-scope deferrals. Critically, these are **not Rule-1b ties**: the contested ligands
   are **Rule-1a-distinct** (RDKit ranks them by Rule 1a; the C/F/Cl spectators can never tie a ring ligand), and the
   *isolation* is exact — `[C@](C1CC1)(C)(F)Cl` (saturated cyclopropyl) **NAMES** while `[C@](C1=CC1)(C)(F)Cl` (the same
   ring with a double bond) **DEFERS**. The trigger is a ring-digraph limitation on **unsaturated ring substituents**,
   distinct from Rule 1b and from `_on_cycle`.
3. **Ring-on-centre** — a stereocentre lying *on* a ring is filtered out of scope by `_on_cycle` before CIP ranking; RDKit
   labels it, we defer (a scope filter, `N[C@]1(F)CCCCO1`).

## The proof (why acyclic Rule 1b is subsumed by Rule 1a) — dalembert

The finding for acyclic centres is not merely empirical; the adversarial hunt (dalembert, tasked to *break* the claim)
instead **proved** the load-bearing lemma:

> **In an acyclic molecule, two ligands tie under CIP Rule 1a ⟺ they are the identical rooted constitution.**

*Proof of the crux* — a **real** C/N/O/S node and a **duplicate** node of the same element never collide in a tree. A real
C/N/O/S node always carries at least one child of Z ≥ 1: either an implicit/explicit **H** (Z = 1) filling its valence, or
the **duplicate-back** atom (Z ≥ 6) generated by its *own* multiple bond. A duplicate leaf `(z, mass, ())` carries only
phantom-0 children. The *only* genuine empty leaves are terminal **halogens and H** — precisely the elements that never
appear as duplicates (they form no multiple bonds). So a real atom and a same-Z duplicate are always separated one sphere
later; the atomic-number-with-duplicates tree faithfully encodes the rooted constitution; and a Rule-1a tie ⟺ identical
rooted constitution. **Rule 1b is a *constitutional* rule** — it can only act on a constitutionally-*distinct* pair that
Rule 1a left tied. Acyclically no such pair exists, so **Rule 1b is inert on trees.** It bites only when a ring closure (or
reconvergent path) lets a duplicate's represented node be reached by a second route of *different* rank — a cycle in the
ranking-dependency a tree structurally cannot contain (matching the literature: Rule 1b's exemplars are ring/mancude
systems — Hanson et al. 2018).

**The crux invariant is pinned** (`duplicate_never_collides_with_real()` in the harness, and a dedicated test): for every
duplicate-capable element, a real terminal node outranks a duplicate leaf of the same element under the shipped
`_cip_compare`. If a future edit ever made H-filling conditional (a radical/charged/hypervalent atom skipping its H) or gave
a duplicate leaf a non-empty child, a real node could become a true empty leaf, collide with a duplicate, and re-open this
gap — the pin reddens first.

**Exhaustive corroboration** (dalembert): every distinct rooted ligand constitution up to 5 heavy atoms over {C,N,O,S,F,Cl,Br}
— **25,212 constitutions, 0 Rule-1a signature collisions**; **300,000** random distinct-constitution pairs through the
*shipped* `_cip_compare` — **0 ties, 0 exceptions**; **30,000** random acyclic single-stereocentre molecules — **2,361
RDKit-labelled, all 2,361 labelled identically by our namer, 0 deferrals, 0 disagreements**.

**Boundary (honest):** the proof is size-independent for the covered element set {C,N,O,S,F,Cl,Br}; hypervalent P/S(VI)/Si
and metals were not analysed (acyclicity keeps the tree argument intact, but the leaf-analysis would need re-checking for
exotic valences). Charged/isotopic/aromatic/ring cases are excluded by the claim's own preconditions. The status is a
proven lemma awaiting a rigorist's (lagrange-grade) sign-off for "Demonstrated"; the argument is in hand.

**What an acyclic deferral actually is (and why it isn't Rule 1b):** acyclic deferrals where RDKit *does* label exist — but
they are **Rule 3 (E/Z geometry)**, not Rule 1b. Minimal case: `C[C@](/C=C\C)(/C=C/C)O` → RDKit R, we defer. The two
propenyl arms are *constitutionally identical* (-CH=CH-CH₃, differing only E vs Z), so by the lemma they tie under Rule 1a
*and* Rule 1b (both constitutional); only Rule 3 can decide, and we defer soundly rather than guess. This does not touch the
Rule-1b claim — it *confirms* it (the acyclic deferral is a different rule).

## The decision

**DEFER Rule 1b (Rung 2) — do not build the `dup_rank` slot / hierarchical-rank pre-pass this round.** Building it now would
be **dead structure** (the zero-call-sites trap: no in-scope molecule reaches a Rule-1b tie) *and* soundness-negative (a
computed-rank pre-pass in CIP's most error-prone region, added for a consumer that provably is not exercised). The
`known-physics-not-new-physics` and zero-call-sites disciplines both forbid it. A self-verifying green test over an
unreachable Rule-1b pass would be worse than no pass at all.

## What is shipped instead (the evidence, committed)

Per "experiments are committed", the finding is pinned by a committed harness rather than left as an uncommitted
measurement — and it doubles as a permanent **differential validation of the shipped Rule-1a+2 namer against an external
oracle** (the opposite of a self-mirror):

- **`experiments/cip_rule1b_consumer_probe.py`** (FROZEN_HASH) — an oracle-verified battery (each RDKit label baked +
  verified at authoring) asserting our namer (a) reproduces every acyclic + saturated-ring label, (b) defers on the ring
  cases RDKit resolves, and (c) the isolation (saturated ring names ↔ unsaturated ring defers). Two **committed sweep
  generators** (`_acyclic_sweep`, `_ring_substituent_sweep`) make the 992/0 and 60→24 counts reproducible, re-run live by
  `_rdkit_cross_check()` when rdkit is present (SKIPS when absent — the committed suite is RDKit-free).
- **`tests/test_cip_rule1b_consumer.py`** — `validate()`, the hash pin, the isolation, and the gated cross-check.

## The real unlock (a different, larger build — NOT Rule 1b)

The in-scope deferrals the investigation found are two distinct **ring-handling** gaps, both separate from Rule 1b:

1. **Unsaturated ring substituents** (off-ring centre) — the newly-characterised gap (24/60 sweep cases): the CIP digraph
   defers when a substituent ring carries a double bond, even where Rule 1a trivially decides. This is the concrete *next*
   CIP consumer if scope is to be extended — a ring-digraph handling improvement, not a new CIP rule.
2. **Ring-on-centre stereocentres** — filtered by `_on_cycle`; supporting them is the deferred Rule-4/5 auxiliary-descriptor
   territory (`CIP_NODE_ENRICHMENT_SCOPE_DECISION_v0.1.md`): ring CIP needs a recursive provisional-R/S pre-pass, and
   populating it incompletely fabricates labels — a large, soundness-critical build, correctly its own future round.

**UNLOCK for Rule 1b specifically: a real, oracle-verified molecule that ties under Rule 1a + Rule 2 yet splits under Rule
1b with a nameable centre.** None exists among the 1052 stereocentres swept.
